# Publishing a Sharp Observation (about 30 seconds)

1. In GitHub, open the `_insights` folder and click **Add file → Create new file**.
2. Name it `YYYY-MM-DD-short-title.md`, e.g. `2026-12-01-compared-to-what.md`.
3. Paste this at the top, then write the note underneath in plain text:

```
---
title: "Compared to what?"
date: 2026-12-01
kind: observation
author: "James Woodeson"
description: "One-line summary shown in lists."
---

Your 200-word note here. Blank line between paragraphs.
```

4. Click **Commit changes**. It's live within a minute or two.

Or simply email the text to Phil and it'll be published for you.
